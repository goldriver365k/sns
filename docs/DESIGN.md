# 디자인 시스템

AI 콘텐츠 매니저의 화면 규칙. 새 화면·기능을 만들 때 이 문서를 먼저 보고 따른다.
화면에서 직접 보려면 **운영 설정 → 디자인 가이드** (`/settings/design`).

- 방향 (2026-11-08 사용자 요청): Canva 홈 화면의 색감·구성을 참고 — 흰·연보라 바탕, 보라 포인트, 첫 화면 하늘색→보라 그라데이션, 둥근 카드, 넉넉한 여백. 다른 회사의 로고·이름·아이콘은 쓰지 않는다.
- 원칙: **같은 역할 = 같은 모양.** 화면마다 클래스를 새로 쓰지 말고 `src/components/ui.ts`에서 가져다 쓴다.

## 1. 토큰 (`src/index.css`)

색 이름의 `cream`·`forest`는 예전 이름을 그대로 둔 것이다(값만 바뀜). 역할로 읽는다.

| 역할 | 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- | --- |
| 바탕 (화면) | `cream-100` | #f5f4fb | 페이지 바탕 |
| 카드 바탕 | `cream-50` | #ffffff | 카드·패널·메뉴 |
| 옅은 칸 | `cream-200` | #eceaf6 | 마우스 올림, 썸네일 바탕 |
| 테두리 | `cream-300` | #dfdcec | 카드·입력 테두리, 구분선 |
| 포인트 (주 색) | `forest-700` | #7d2ae8 | 주 버튼, 선택됨, 링크 |
| 포인트 밝게 | `forest-500` | #8b3dff | 입력 테두리(포커스), 그라데이션 |
| 포인트 옅게 | `forest-50` / `forest-100` | #f4eeff / #e7dcff | 선택된 메뉴 바탕, 포커스 링 |
| 포인트 짙게 | `forest-900` | #3a1a7a | 주 버튼 마우스 올림 |
| 글자 | `ink` | #0e1318 | 본문·제목 |
| 흐린 글자 | `muted` | #6b6f80 | 설명·도움말 |
| 상태 | `ok` / `warn` / `danger` | #0f8a5f / #b45309 / #c62828 | 성공·주의·오류 글자 |

- 그림자: `shadow-card`(카드 평소), `shadow-pop`(팝업·떠 있는 것). 둘 다 보라 기운이 살짝 있다.
- 그라데이션: `.hero-gradient`(첫 화면 위쪽 큰 영역만), `.text-gradient`(첫 화면 큰 제목만). 남발하지 않는다.
- 모서리: 큰 영역 28px · 카드 `rounded-2xl`(16px) · 입력·버튼 `rounded-xl`(12px) · 작은 칸·썸네일 `rounded-lg`(8px) · 고르기 알약 `rounded-full`.

## 2. 글자 크기

| 단계 | 클래스 (ui.ts) | 크기 | 쓰는 곳 |
| --- | --- | --- | --- |
| 화면 제목 | `pageTitle` | 24 → 28px, 굵게 | 화면 맨 위 한 번 (PageHeader) |
| 묶음 제목 | `sectionTitle` | 20 → 24px, 굵게 | 화면 안 큰 묶음 (예: 디자인 계속하기) |
| 카드 제목 | `cardTitle` | 14px, 굵게 | 카드 맨 위 |
| 본문 | `text-[15px]` | 15px | 주 입력·설명 |
| 작은 본문 | `text-sm` | 14px | 패널 안 버튼·입력 |
| 설명 | `text-xs` | 12px | 라벨·부가 정보 |
| 도움말 | `help` | 11px | 버튼 아래 짧은 안내 |

글꼴은 Pretendard. 한국어는 `word-break: keep-all`(낱말 단위 줄바꿈)이 전체에 걸려 있다.

## 3. 공용 스타일 (`src/components/ui.ts`)

| 종류 | 이름 | 언제 |
| --- | --- | --- |
| 영역 | `card` / `cardLg` | 설정 묶음, 결과 칸 / 넓은 설정 화면 |
| | `panel` | 카드 안의 하위 묶음 |
| | `emptyBox` | 아직 없음·다음 단계 안내 (점선) |
| 입력 | `fieldLabel` + `inputBase` | 큰 주 입력 폼 (게시물 만들기) |
| | `label` + `field` | 편집 패널 안 작은 입력 |
| 버튼 | `btnPrimary` / `btnPrimarySm` | 화면·카드마다 가장 중요한 동작 **하나** |
| | `btnSecondary` | 두 번째 동작 (보라 테두리) |
| | `btnGhost` | 조용한 동작 (취소, 다시 생성) |
| | `btnDanger` | 삭제 (왼쪽 끝) |
| | `btnLink` | 글자 버튼 (수정, 추가, 모두 보기) |
| 고르기 | `chip(on)` | 알약 모양 — 언어, 배경 종류처럼 여러 개 |
| | `seg(on)` | 칸 나눔 — 영상 길이처럼 나란한 몇 개 중 하나 |
| 안내 | `help` / `errorText` / `okText` | 도움말 / 오류 / 완료 |

## 4. 화면 구성

- **왼쪽 메뉴 (PC)**: 좁은 아이콘 메뉴 92px — 맨 위 둥근 [+ 만들기], 아이콘 위·짧은 이름 아래, 선택된 메뉴는 옅은 보라 칸 + 보라 글자, 맨 아래 계정. 휴대폰은 위쪽 바 + 서랍 메뉴.
- **화면 맨 위**: `PageHeader`(제목 + 한 줄 설명 + 오른쪽 동작). 하위 탭이 있으면 오른쪽에 알약 탭(릴스).
- **제작 화면 3단**: 왼쪽 설정 / 가운데 미리보기 / 오른쪽 실행(만들기·내보내기). 휴대폰은 미리보기 → 실행 → 설정 순으로 쌓는다.
- **첫 화면**: 그라데이션 큰 영역(질문 + 찾기) → 색 아이콘 도구 줄 → 디자인 계속하기 카드.
- 여백: 카드 안 `p-4`(넓으면 `p-5~6`), 카드 사이 `gap-4`, 큰 묶음 사이 `mt-8~10`.

## 5. 도구 아이콘 색 (첫 화면)

도구마다 고정된 2색 그라데이션을 쓴다(같은 도구는 어디서나 같은 색): SNS 게시물 분홍→주황 · 자동 릴스 보라 · 털복이 주황 · 핵심어 노랑 · 상품 사진 청록 · 글자 포스터 남보라 · 오늘 주황 · 캘린더 초록 · 지난 콘텐츠 파랑 · 보관함 하늘 · 설정 회색 (`src/pages/Home.tsx`의 `TOOLS`).

## 6. 하지 말 것

- 화면마다 `const box = '...'`처럼 같은 모양을 새로 정의하기 → `ui.ts`에 없으면 거기에 추가한다.
- 한 카드에 주 버튼 두 개 이상.
- 회색·검정 등 임의의 색 코드를 화면 틀에 직접 쓰기 (생성되는 카드·영상 안의 색은 콘텐츠 디자인이라 예외).
- 그라데이션을 일반 버튼·카드에 쓰기.
- 아이콘만 있고 이름 없는 버튼 (꼭 필요하면 `aria-label`과 `title`).

## 7. 아직 남은 것 (점진 적용)

- 오래된 화면(게시물 만들기 결과, 카드 편집기, 상품 사진 편집기 패널, 털복이·핵심어 세부)에는 아직 직접 쓴 클래스가 남아 있다. 그 화면을 고칠 때 `ui.ts`로 바꾼다.
