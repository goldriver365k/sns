# 엑셀·워드 문서 도구 (별도 프로그램)

SNS 사이트(AI 콘텐츠 매니저)와 **따로 쓰는** 프로그램입니다. 사이트 메뉴에는 없고, 사이트 빌드에도 들어가지 않습니다.

## 쓰는 법
1. `release/엑셀워드도구-v5.html` 파일을 내려받습니다.
2. 더블클릭하면 크롬·엣지 등 브라우저에서 열립니다. 설치·로그인·인터넷 연결이 필요 없습니다.
3. 엑셀(.xlsx)·워드(.docx) 파일을 끌어다 놓거나 [파일 열기] → 고친 뒤 [.xlsx 저장]/[.docx 저장] → 다운로드 폴더에 저장됩니다.

파일은 어디로도 보내지 않고 브라우저 안에서만 처리합니다. USB·메일로 HTML 파일을 옮겨 다른 PC에서도 쓸 수 있습니다.

## 할 수 있는 것
- **공통**: 위쪽 도구 모음 [파일 ▾]·[열기]·[저장]·[인쇄], 창 어디에나 파일 끌어다 놓기, **보기 100%·80%·50% 버튼**과 화면 배율(25~200%, 마지막 배율 기억)
- **단축키**: Ctrl+O 열기 · Ctrl+S 저장 · Ctrl+P 인쇄 · Ctrl+Z 되돌리기 · Ctrl+C/X/V 복사·잘라내기·붙여넣기 · Ctrl+A 전체 선택
- **엑셀 보기**: 원래 서식 그대로(글꼴·굵게·색·채우기·테두리·맞춤·줄바꿈·병합·열 너비·행 높이·숨긴 행열), 엑셀에 저장된 배율, [화면 맞춤]으로 표 전체를 한 화면에
- **엑셀 작업**: 끌어서 범위 선택(Shift+클릭·Shift+화살표, 행·열 머리글 클릭), 셀 고치기(숫자·글자·날짜·`=수식`), 되돌리기, 찾기, 아래쪽에 선택 범위 개수·합계·평균, 시트 탭
- **잘라내기·복사·붙여넣기**: 도구 모음 [✂ 잘라내기][⧉ 복사][📋 붙여넣기], 셀 오른쪽 클릭 메뉴(값만 붙여넣기·내용 지우기 포함), Ctrl+X/C/V. 복사한 범위는 점선으로 표시(Esc 로 취소)
  - 이 프로그램 안에서는 값·수식·서식(글꼴·채우기·테두리)을 함께 옮기고, 수식의 칸 주소는 옮긴 만큼 바뀝니다(=C2*D2 → =C5*D5, $ 붙은 주소는 그대로)
  - 잘라내기는 붙여넣을 때 옮겨지고(원래 칸은 비워짐) 수식은 그대로 옮겨집니다
  - 엑셀·메모장 등 다른 프로그램과는 글(탭 구분)로 주고받습니다. 브라우저가 버튼 붙여넣기를 막으면 이 안에서 복사한 것만 붙여넣어지고, 다른 프로그램 것은 Ctrl+V 로
- **그림으로 복사**: [📷 그림으로 복사] 또는 오른쪽 클릭 → 고른 범위(한 칸만 골랐으면 인쇄 영역 또는 표 전체)를 화면과 같은 서식의 그림(PNG)으로 클립보드에 넣음 → 카카오톡·문서에 Ctrl+V. 브라우저가 막으면 PNG 파일로 저장. 오른쪽 클릭 [그림으로 저장 (PNG)]도 있음
- **워드 잘라내기·복사·붙여넣기**: 문단을 눌러 고치는 중에 글자를 고르고 버튼 또는 Ctrl+X/C/V
- **열 너비·행 높이**: 열 머리글 오른쪽 경계·행 머리글 아래 경계를 끌어서 넓히고 줄이기, 경계를 두 번 누르면 내용에 맞춤, [↔ 열 너비 맞춤]은 고른 열들을 내용에 맞춤. 여러 열(행)을 머리글로 고른 뒤 끌면 함께 바뀜. 되돌리기 가능, 저장하면 엑셀에서도 그대로
- **인쇄 영역**: 범위를 고르고 [인쇄 영역 지정] → 표에 파란 점선 표시. 저장하면 엑셀에서도 같은 인쇄 영역이 쓰인다(엑셀에서 지정한 인쇄 영역도 읽음)
- **엑셀 인쇄**: 범위(인쇄 영역/선택한 범위/시트 전체), A4 세로·가로(엑셀 인쇄 설정을 기본값으로), 용지 너비에 맞춰 줄이기, 눈금선 인쇄 → 브라우저 인쇄 창(프린터 또는 PDF로 저장)
- **워드**: 제목·글자 모양·표·그림 보기 / 문단 고치기(굵게·색·그림 유지), 제목 1~3, 굵게·기울임·밑줄, 맞춤, 문단 추가·삭제, 찾아 바꾸기 / 인쇄(편집 표시 없이 본문만) / .docx·.txt 저장
- 고친 부분만 바꿔 넣으므로 이 화면에 안 보이는 서식·차트·머리글 등은 그대로 남습니다.

## 하지 않는 것
- 수식 계산: 고친 칸과 관계된 수식 칸에는 고치기 전 값이 보입니다. 저장한 파일을 엑셀에서 열면 다시 계산됩니다.
- 행·열 삭제, 시트 추가, 글꼴·색 바꾸기(수식 참조가 깨질 수 있어 엑셀에서).
- 예전 형식(.xls·.doc)과 암호가 걸린 파일.

## 고쳐서 다시 만들기
저장소 최상위에서:

```bash
npm run build:office
```

결과물 `tools/office-viewer/dist/엑셀워드도구-v(버전).html`을 `release/`에 복사해 올립니다(예전 버전 파일은 지움). 고칠 때마다 `vite.config.ts`의 `VERSION`을 올려 화면·파일 이름의 버전이 바뀌게 합니다. 스크립트·스타일은 모두 HTML 안에 들어갑니다(`vite.config.ts`의 `singleFile`).

- `src/office/` — 파일 읽기·고치기·저장 (xlsx·docx는 ZIP 안 XML. JSZip 사용)
- `src/office/xlstyle.ts` — 엑셀 셀 서식(글꼴·채우기·테두리·맞춤·테마 색) → CSS
- `src/components/` — 엑셀 표(SheetView, sheetRender, 그림으로 복사 sheetImage), 워드 문서(DocView), 인쇄(Print: 설정 창·인쇄용 표, `#print-root`에 그림), 배율(Zoom)
- `src/App.tsx` — 시작 화면·열기·저장
