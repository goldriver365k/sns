# AI 자동 릴스 — 개발 문서

기존 SNSROOM에 추가한 메뉴. 주제·대본·사진·영상으로 1080×1920 세로 릴스를 구성한다.
기존 기능·디자인은 그대로 두고 `src/reels/`, `src/components/reels/`, `src/pages/reels/`에만 추가했다.

## 1단계 (완료) — 메뉴, 제작 화면, 업로드, 타임라인, 디자인 5종, 모션그래픽 미리보기

| --- | --- | --- |

### 화면 그리기 구조
- `src/reels/render.ts`의 `drawReelFrame(ctx, project, t)` — **t초의 화면을 시간만으로 그린다**(난수도 장면 id로 고정). 그래서 다음 단계 MP4 제작 때 같은 함수로 프레임을 하나씩 뽑으면 미리보기와 같은 영상이 된다.
- 미리보기는 1080×1920 캔버스를 화면에 맞춰 줄여 보여 준다. 영상 자료는 지금 장면일 때만 재생 위치를 맞춰 돌린다(소리 없음).

### 아직 없는 것 (화면에 "다음 단계"로만 안내, 작동하는 척하지 않음)
AI 대본·장면 생성과 재작성, 장면 AI 재생성, 한국어 AI 목소리, 배경음악, 음성 동기화 자막, MP4 제작·다운로드, 프로젝트 저장·다시 편집. 자료와 장면은 새로고침하면 사라진다.

## 다음 단계 제안 (사용자 승인 후 진행)

1. **MP4 제작(사용자 PC에서 처리)** — 브라우저 WebCodecs로 H.264 인코딩 + MP4 포장. 서버 비용 없음. WebCodecs를 못 쓰는 브라우저는 안내(또는 ffmpeg.wasm 대안 검토).
2. **프로젝트 저장** — 장면·설정은 Firestore, 사진은 기존 `images` 저장소 재사용. 영상 파일은 Firestore 1MB 제한 때문에 저장 방식 결정 필요(브라우저 내부 저장 IndexedDB 또는 Storage — Storage는 유료 요금제가 필요할 수 있어 승인 필요).
3. **AI 대본·장면 생성** — 기존 OpenAI 서버 함수 방식 재사용(키는 Netlify 환경변수에만). API가 없으면 직접 입력 또는 로컬 AI 주소 연결.
4. **한국어 목소리·배경음악·자막 동기화** — 아래 라이선스 확인 후 결정.

## 라이선스 검토 (상업적 사용) — 도입 전 최종 확인 필요

| 후보 | 용도 | 라이선스·조건 (알고 있는 내용, 도입 시 공식 문서로 재확인) | 판단 |
| --- | --- | --- | --- |
| 자체 캔버스 렌더러 (현재) | 모션그래픽·미리보기 | 직접 작성 | 사용 중 |
| WebCodecs (브라우저 기본 기능) | MP4 인코딩 | 브라우저 기능, 별도 라이선스 없음. H.264 지원은 브라우저마다 다름 | 1순위 |
| mp4-muxer 계열 라이브러리 | MP4 포장 | MIT 계열로 알려짐 | 도입 시 확인 |
| ffmpeg.wasm | 인코딩 대안 | 코어는 LGPL, x264 등 포함 빌드는 GPL 조건이 붙을 수 있음 | 대안으로만 검토 |
| Remotion | 복잡한 모션그래픽 | 개인·소규모(일정 인원 이하) 무료, 그 이상은 회사용 유료 라이선스 | 지금 구조로 충분해 **도입 보류**. 필요해지면 조건 확인 후 승인 요청 |
| 브라우저 내장 음성(speechSynthesis) | 미리 듣기 | 무료지만 기기마다 목소리가 다르고 파일로 녹음하기 어려움 | 미리 듣기용으로만 |
| 로컬 TTS(예: MeloTTS·Piper 등) | 한국어 목소리 파일 | 엔진과 **목소리 모델의 라이선스가 따로**이며 모델마다 상업 이용 조건이 다름 | 모델별 확인 후 제안 |
| 무료 배경음악 | BGM | 출처마다 조건이 다름(저작자 표시, 재배포 금지 등) | 직접 고른 곡 업로드 우선, 기본 제공곡은 조건 확인 후 |

폰트는 기존 카드와 같은 5종(Noto Sans KR, Pretendard, 배민 주아체, 마루 부리 — OFL / 카페24 써라운드에어 — 카페24 약관)을 쓴다.
