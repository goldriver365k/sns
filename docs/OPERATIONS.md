# 운영 안내

사이트: https://snsroom.netlify.app (관리자 `higidia@gmail.com`만 로그인 가능)

## 1. 매일 쓰는 법

1. **SNS 게시물 만들기**
   1. SNS → 브랜드 → 콘텐츠 계획을 고릅니다. 오늘 요일 계획이 자동으로 선택됩니다.
   2. 내용과 이미지를 넣고 언어를 고른 뒤 [자동 완성]을 누릅니다.
   3. 생성이 끝나면 첫 결과가 **자동으로 복사**됩니다. 휴대폰은 [복사하기]를 한 번 누르세요.
   4. 고정 해시태그는 복사할 때 항상 붙습니다.
   5. 글은 그 자리에서 고치면 자동 저장됩니다.
2. **인스타그램 카드**
   - 디자인 5종 중에서 고릅니다.
   - [편집기에서 수정]으로 글씨·사진을 옮기고 폰트·색을 바꿉니다.
   - 저장은 [갤러리에 저장](휴대폰) 또는 PNG·ZIP으로 합니다.
3. **확인과 승인**
   - [승인]은 검토를 마쳤다는 표시입니다.
   - 오늘의 콘텐츠, 지난 콘텐츠, 콘텐츠 캘린더에서 다시 보고, 복사하고, 고칠 수 있습니다.
4. **브랜드·계획 관리**
   - **운영 설정 → 브랜드 관리**에서 합니다: 순서, 사이트 주소, 고정 해시태그, 기본 카드 디자인, 주간·월간 계획.
5. **AI 자동 릴스**
   - 대본·사진·영상을 넣으면 자동 저장됩니다. **내 프로젝트** 탭에서 다시 열어 편집하고 MP4를 다시 만듭니다.
   - 영상 파일은 넣은 기기에만 저장됩니다. 다른 기기에서 열면 [다시 넣기]로 같은 영상을 넣어 주세요.
   - 브랜드와 주제를 넣고 [✨ 주제로 AI 대본·장면 만들기], 붙여넣은 글은 [✨ AI로 다듬기], 장면 하나는 [✨ AI로 다시 쓰기]. 마음에 안 들면 [↩ 되돌리기].
   - **목소리·배경음악** 칸: 목소리·말투·속도를 고르고 [▶ 미리 듣기] → [🎙 음성 만들기]를 누르면 장면 길이가 말에 맞춰집니다. 자막을 고치면 [음성 만들기]를 다시 누릅니다(바뀐 장면만 새로 만들어 비용이 듭니다). 배경음악은 기본 음악 또는 내 음악 파일(상업 이용 가능한 곡만).
   - **디자인** 칸 아래 "다른 형식 디자인으로 만들기"에서 털복이 숏폼·핵심어 타이포 디자인을 고르면, 이 릴스 자막을 그 형식으로 옮겨 그 탭이 열립니다([AI로 맞춰 옮기기] 또는 [그대로 옮기기]).
   - 가격은 주제에 적은 것만 가격표에 들어갑니다. OpenAI 대신 PC의 로컬 AI를 쓰려면 릴스 **설정** 탭에서 바꿉니다.

## 2. 문제가 생겼을 때

| 증상 | 확인할 것 |
| --- | --- |
| [자동 완성]에서 오류 | 빨간 문구를 그대로 확인합니다. `OpenAI 401` = 키 오류, `404` = 모델 이름 오류, `429` = 결제·한도 문제 |
| 무엇이 빠졌는지 모르겠음 | **운영 설정 → 서버 연결 점검**에서 "없음"인 항목을 Netlify 환경변수에 넣고 다시 배포합니다 |
| "접근 권한이 없는 계정" | 관리자 계정으로 로그인했는지 확인합니다 |
| 로그인 팝업이 안 뜸 | 브라우저 팝업 차단을 풉니다. 새 주소로 옮겼다면 Firebase → Authentication → 승인된 도메인에 추가합니다 |
| "화면을 표시하지 못했습니다" | 새 버전 배포 직후라면 [새로고침]으로 해결됩니다 |
| 카드 저장이 막힘 | 안내 문구대로 글을 줄이거나, 카드 밖으로 나간 요소를 안으로 옮깁니다 (편집기 [이 카드 배치 초기화]) |
| 맨 위 빨간 줄 "인터넷 연결이 끊겼습니다" | 연결되면 수정 내용이 자동으로 저장됩니다 |

## 3. 배포

- 운영 사이트는 GitHub `goldriver365k/sns`의 **`main` 브랜치**를 Netlify가 자동 배포합니다.
- 새 작업은 작업 브랜치에서 하고, 확인이 끝나면 `main`에 합치면 자동으로 배포됩니다.

## 4. 설정 바꾸기

- **환경변수:** Netlify → Project configuration → Environment variables에서 바꿉니다. 바꾼 뒤에는 **반드시 Deploys → Trigger deploy**를 누릅니다.
  - `OPENAI_API_KEY`, `OPENAI_MODEL`: 필수
  - `OPENAI_REASONING_EFFORT`: 선택
  - `ADMIN_EMAILS`, `VITE_ADMIN_EMAILS`
- **관리자 이메일을 바꿀 때**는 아래 세 곳을 함께 고칩니다.
  1. `firestore.rules`·`storage.rules`의 이메일 목록 → Firebase 콘솔에 게시
  2. Netlify 환경변수 `ADMIN_EMAILS`, `VITE_ADMIN_EMAILS`
  3. 다시 배포
- **SNS 노출 기준:** 플랫폼 정책이 바뀌면 `shared/sns.ts` 한 곳에서 고칩니다. 해시태그 개수, 글자 수, 노출 핵심 항목이 여기에 있습니다.

## 5. 보안 요약

- OpenAI 키 등 비밀값은 Netlify 환경변수에만 있고, 저장소·브라우저 코드에는 없습니다. 2026-10 점검 결과 저장소 기록 전체에서도 발견되지 않았습니다.
- 서버 함수(generate, health, image, reel-script, reel-voice, tteolbok-copy, tteolbok-voice, keyword-copy)는 모두 Firebase 로그인 토큰과 관리자 이메일을 확인한 뒤에만 실행됩니다.
- Firestore는 관리자 이메일(인증된 이메일)만 읽고 쓸 수 있습니다. 로그인하지 않은 접근이 막히는 것을 확인했습니다.
- 브라우저 코드에 들어 있는 Firebase 웹 설정값과 관리자 이메일은 원래 공개되는 값입니다(Netlify 비밀값 검사 예외 처리).
- 사이트는 검색엔진 노출 금지(noindex), 다른 사이트 안에 넣기 금지(X-Frame-Options), 카메라·마이크·위치 사용 금지 헤더를 씁니다.
